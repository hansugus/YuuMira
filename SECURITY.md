# YuuMira Security Policy

[**English**](./SECURITY.md) · [简体中文](./SECURITY_CN.md)

## Reporting a vulnerability

Do not report a suspected security vulnerability through a public Issue.

Email `support@yuuone.app` with this subject format:

```text
[Security][YuuMira] Brief vulnerability description
```

Include as much of the following as possible:

- Affected YuuMira version and operating system
- Description, impact, and potential risk
- Repeatable validation steps or a minimal proof of concept
- Any known temporary mitigation
- A safe way to contact you

Do not send unnecessary real user data, active credentials, or other sensitive content. We will acknowledge the report and assess its impact. Keep the information private until we agree on remediation and disclosure.

If you suspect an API key, OAuth token, or other credential has been exposed, revoke and rotate it with the relevant provider immediately. Do not wait for the vulnerability investigation to finish.
