Welcome to the **YuuMira Support Center**. YuuMira is a local-first agent workspace that keeps complex work moving through boards, knowledge, session goals, computer use, and automation.

This repository publicly tracks bug reports, usage questions, feature requests, and product feedback for YuuMira.

## Get support

Choose the most appropriate English template from the [issue template chooser](../../issues/new/choose):

- **Bug report**: Unexpected behavior, crashes, or installation/update failures.
- **Usage help**: Questions about configuration, connections, permissions, or workflows.
- **Feature request**: Ideas for new or improved capabilities.

Before submitting:

1. Check the [English documentation](https://agents.yuuone.app/docs/) and search existing Issues.
2. Reproduce the problem on the latest version when possible.
3. Prepare your YuuMira version, operating system, reproduction steps, expected result, and actual result.
4. Remove API keys, tokens, personal information, and sensitive workspace content from logs, screenshots, and configuration.

> **Do not open a public Issue for a security vulnerability.** Read the [Security Policy](./SECURITY.md) and report it privately to `support@yuuone.app`.

## Repository scope

This is YuuMira's technical-support repository. It does not contain the application source code or release installers. `runtime/` only provides Windows runtime prerequisites; see [`runtime/README.md`](./runtime/README.md).
