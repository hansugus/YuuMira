# 第 09 集｜练习与核验清单

## 开始之前（只能在 macOS 上练习）
- [ ] 已连接一个可用模型（本集演示用 Opus 5.5，换成其他模型时措辞、耗时和步骤数会不同）。
- [ ] 「设置 → 应用 → 工具 → 电脑操控」已打开（默认关闭）。
- [ ] 同页「系统权限」里「辅助功能」「屏幕录制」都显示「已授权」。授权要你本人在 macOS 系统设置里完成；若系统设置里已勾选但这里仍显示未授权，按页面提示「重置授权记录」后重新授权。

## 操作
1. 新建会话，把权限模式切到「询问」。
2. 把 `request.txt` 粘贴进输入框，发送。
3. AI 要动手时会停下来出现「需要权限」卡片，看清后点「允许」。本集演示中一共批准了两次：打开计算器、按键。
4. 等它在计算器里按完，看回答。

## 必须核对的结果
- [ ] 计算器显示 `6×18×12` 和 `1,296`。
- [ ] AI 回答的结果是 1,296 元，与 `expected-result.md` 手算一致。

## 需要知道的行为（2026-10-07 在 0.12.3 本地编译版实测）
- 只「看」窗口内容（读按钮和文字）不需要批准；在「询问」模式下，打开应用、点击、输入都要先批准。
- 「始终允许」会在本会话内记住这条命令，之后同类操作不再询问。电脑操控建议每次自己批准。
- 点「允许」会把 YuuMira 窗口提到前面，如果它和被操作的应用重叠，你可能看不到按键过程；把两个窗口错开摆放即可。
- AI 有时会给自己设一个核对条件（例如期望看到「1296」），计算器显示「1,296」时步骤会标红「错误」，但结果本身是对的；以计算器实际显示为准。
- 涉及密码、付款、个人资料的操作不要交给电脑操控。
