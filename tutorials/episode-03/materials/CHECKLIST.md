# 第 03 集｜练习与核验清单

## 开始之前
- [ ] 已完成第 01、02 集练习，会话列表里至少有 2 个会话；没有也可以随便新建两个会话来练。
- [ ] 确认左上角显示的是你要整理的 Workspace（工作区）；列表和看板只显示当前工作区的会话。

## 操作
1. **改状态**：在会话列表里点会话前面的小圆圈，把一件“做完了、等你核对”的事改成「待审查」。
2. **标优先级**：右键会话 →「标签」→「Priority」→ 选一个：
   - Critical＝重要且紧急，Planned＝重要不紧急，Delegated＝不重要但紧急，Eliminated＝不重要不紧急。
3. **打开看板**：点会话列表上方「列表 / 看板」中的「看板」，先看「四象限」，再切「泳道」，把「分组」选成「状态」。
4. **关闭任务**：自己核对过结果后，点开这个会话，在输入框上方把状态改成「完成」。
5. **归档**：右键不再需要的会话 →「归档」；在左侧「已归档」里还能找到。

## 必须核对的结果
- [ ] 侧栏各状态后面的数字，与你的改动一致。
- [ ] 四象限里，贴了标签的会话在对应格子；没贴的在第四格（不重要不紧急）。
- [ ] 改成「完成」的会话仍在看板「完成」列里；归档的会话从列表和看板里消失，出现在「已归档」。

## 需要知道的行为（2026-10-03 在 0.12.3 实测）
- 新会话默认状态是「待办」。默认没有「进行中」状态。
- 优先级标签名目前是英文（Critical / Planned / Delegated / Eliminated）；四象限每格下方有中文说明。
- **没贴优先级标签的会话会显示在第四格「不重要不紧急」**，只代表还没标，不代表真的不重要。
- 状态图标弹出的菜单最后一项「Archive」目前是英文，作用就是归档。
- 「完成」不会让会话从看板消失；要移走用「归档」。
- 看板上方的「新建任务」是进阶功能（任务编排），本集不讲。
