# 第 01 集｜练习与核验清单

## 开始之前
- [ ] 已安装 YuuMira，并连接一个可用模型；本集不包含登录、授权或安装教学。
- [ ] 新建会话，使用“探索”模式。本练习只整理文字，不修改文件。
- [ ] 使用此目录的虚构资料，不粘贴真实客户信息、密钥或验证码。

## 操作
1. 将 `prompt.txt` 全文粘贴到输入框并发送。
2. 等待回答，不要求措辞与视频完全一致。
3. 对照下方事实，检查摘要、待办表、待确认事项。
4. 在同一个会话发送 `followup-prompt.txt`，把缺口转成澄清问题。
5. 若有遗漏或猜测，指出 M 编号并要求修正，不直接接受结果。

## 必须核对的事实
- [ ] M2：首批仅邀请 **20 名内测用户**；不等于已经公开上线。
- [ ] M3：林可，内测反馈表，**2026-10-03 18:00**。
- [ ] M4：周宁，两张引导页插图，**2026-10-04 18:00**。
- [ ] M5：陈雨，邀请邮件草稿，**2026-10-05 12:00**；**未授权发送**。
- [ ] M6：帮助中心常见问题，负责人、截止日期均为“待确认”。
- [ ] M2/M7：公开上线日期、定价、下次会议时间未决定。
- [ ] 年份来自会议日期 M1，而不是电脑当天日期。
- [ ] 表格依据编号能回到原文找到，不凭空生成引用。
- [ ] 没有执行待办、发送邮件或把未定事项说成已获批准。

## 完成标准
信息准确、缺口保留、行动未越界即可；不要求表格外观或措辞完全相同。一个整齐的表格不是事实正确的保证。
