# 第 02 集｜练习与核验清单

## 开始之前
- [ ] 已完成第 00 集：安装 YuuMira 并连接一个可用模型。
- [ ] 把 `faq-draft.md` 复制到一个单独的练习文件夹；不要用真实工作文件练习。
- [ ] 新建会话，确认输入框上方的模式是「探索」。

## 操作
1. 在输入框下方点 **Work in Folder**，选择练习文件夹。
2. 粘贴 `prompt.txt` 并发送，等待计划卡片（Plan）。
3. 此时打开练习文件：内容应当**没有任何变化**。
4. 把模式切到「询问」，再点「接受计划」→ 选「接受」。
5. 每次弹出「需要权限」：看 Tool（Edit 是改文件，Bash 是运行命令）和路径，再点 Allow 或 Deny。
6. 完成后，打开练习文件，与 `expected-result.md` 逐行对照。

## 必须核对的结果
- [ ] 邀情 → 邀请、反溃 → 反馈、保流 → 保留。
- [ ] 10月8号 → 2026-10-08；2026/10/12 → 2026-10-12，18:00 保留。
- [ ] 4 个问题都在，顺序和意思没变；第 3 题没有被补上日期。
- [ ] 探索模式下文件没有被修改；每处修改都是你批准后才写入。

## 需要知道的行为（2026-10-02 在 0.12.3 实测）
- 在「探索」中直接点「接受」，模式会自动切到「执行」，之后不再逐项询问。想逐项把关，接受前先切到「询问」。
- 「接受计划」菜单里另有「接受并压缩」，适用于复杂或较长的计划；本练习选「接受」。
- 审批按钮目前显示英文：Allow / Always Allow / Deny。Always Allow 只在本会话内记住同一条命令；实测中，之后的修改和复核命令仍然弹出了审批。
- 模型措辞、修改次数和等待时间可能与视频不同；以文件实际内容为准。
