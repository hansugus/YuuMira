欢迎来到 **YuuMira 技术支持中心**。YuuMira 是一款本地优先的 Agent 工作台，帮助你通过看板、知识库、会话目标、电脑操作与自动化持续推进复杂工作。

本仓库用于公开跟踪 YuuMira 的错误报告、使用问题、功能建议与产品反馈。

- [完整支持说明](./SUPPORT_CN.md)

## 获取帮助

请从 [Issue 模板选择器](../../issues/new/choose)选择最合适的中文模板：

- **错误报告**：功能异常、崩溃、安装或更新失败。
- **使用求助**：配置、连接、权限或工作流相关问题。
- **功能建议**：希望新增或改进的能力。

提交前请先：

1. 查阅[中文文档](https://agents.yuuone.app/docs/zh-Hans/)并搜索现有 Issues。
2. 尽可能在最新版本中复现问题。
3. 准备 YuuMira 版本、操作系统、复现步骤、预期结果与实际结果。
4. 删除日志、截图和配置中的 API Key、Token、个人信息及工作区敏感内容。

> **安全漏洞请勿创建公开 Issue。** 请阅读[安全策略](./SECURITY_CN.md)，通过 `support@yuuone.app` 私密报告。

## 仓库范围

这是 YuuMira 的技术支持仓库，不包含应用源代码或正式安装包。`runtime/` 仅提供 Windows 运行库依赖，详见 [`runtime/README_CN.md`](./runtime/README_CN.md)。
