# YuuMira Support Guide

[**English**](./SUPPORT.md) · [简体中文](./SUPPORT_CN.md)

## Scope of support

You can use this repository to report YuuMira issues involving:

- Installation, startup, updates, and crashes
- Model providers, network proxies, and credential configuration
- Sources, MCP, APIs, and local-filesystem connections
- Conversations, workspaces, permissions, skills, automation, and computer use
- UI, performance, accessibility, and localization
- Feature requests and product feedback

For billing, quotas, account restrictions, or outages belonging to a third-party model or platform, contact that provider first. General programming questions unrelated to YuuMira are outside this repository's scope.

## Before submitting

1. Read the [English documentation](https://agents.yuuone.app/docs/).
2. Search existing Issues to avoid duplicates.
3. Upgrade to the latest version and verify again when practical.
4. Choose an [English Issue template](../../issues/new/choose) and complete all required fields.

## Useful diagnostic information

- Full YuuMira version
- Operating-system version and CPU architecture
- Affected feature or connection type
- Minimal, repeatable steps
- Expected and actual results
- Error messages, relevant logs, screenshots, or recordings
- Whether the problem is consistent, when it started, and the last known working version

Only share the minimum information needed to diagnose the issue. Remove API keys, OAuth tokens, cookies, personal information in file paths, and sensitive workspace, conversation, or knowledge-base content. If a credential was exposed, revoke and rotate it with the provider immediately.

## What to expect

Maintainers may ask for more information, a smaller reproduction, or verification of a candidate fix. Duplicate, non-reproducible, persistently incomplete, or out-of-scope Issues may be closed. Public Issues are not suitable for security vulnerabilities or other sensitive information.

Follow the [Security Policy](./SECURITY.md) for security reports. For other matters that require private communication, email `support@yuuone.app`.
